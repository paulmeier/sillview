    Sillview¶

    A desktop dashboard for your financial ledger.

    Get started Architecture Download

    Sillview is a macOS desktop app that turns the kasas financial ledger into a dashboard you can actually look at. Build your own dashboards from a marketplace of widgets, arrange them on a draggable, resizable grid, and save them locally.

    It is built with Electron Forge + Vite + React 19 + TypeScript, styled with Tailwind CSS v4, and visualized with Tremor-style charts (Recharts).

    The defining trait: Sillview bundles and manages the kasas backend for you. There is no separate server to install or run — on first launch it starts kasas on a private loopback port, connects automatically, and can even keep it running in the background and update it in place.

    What you get¶

    • Custom dashboards

      Arrange widgets on a draggable, resizable grid. Save as many dashboards as you like — they persist locally on your machine.

      Dashboards & widgets

    • Widget marketplace

      Browse a catalog of widgets by category — net worth, accounts, cash flow, spending, live activity — and drop them onto a dashboard.

      Widget catalog

    • Managed backend

      Sillview ships the kasas binary, copies it to a writable location, generates its config, starts it on loopback, and connects automatically. No separate server to run.

      Managed backend

    • Background mode

      Opt in to an OS service (macOS LaunchAgent / Linux systemd user unit) that keeps kasas syncing even when Sillview is closed — your data stays fresh.

      Background mode

    • In-app backend updates

      Sillview drives kasas's own verified self-update (HTTPS + SHA-256 + atomic replace) and restarts it — one click, no manual downloads.

      Backend updates

    • Offline mock mode

      Run the entire UI on in-memory fixtures — no backend, no network, no real data. The fastest way to iterate on widgets and layout.

      Mock mode
